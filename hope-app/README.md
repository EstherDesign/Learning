# 희망 Hope 🌟

**현대 도시인을 위한 성경 말씀 위로 서비스**

삶의 어려움 속에서 성경을 통한 희망과 위로를 전하는 웹 애플리케이션입니다.

## 📖 프로젝트 소개

Hope는 30대 후반~40대 초반의 가장과 여성들이 일상에서 겪는 다양한 어려움(스트레스, 육아, 불안, 우울 등)에 대해 성경 말씀을 통한 위로와 희망을 제공합니다.

### 핵심 가치
- ✨ **실제 성경 말씀**: 과장 없이 성경(개역개정판)의 실제 구절만 사용
- 💝 **공감하는 위로**: 현대인의 실제 고민에 공감하는 말씀 큐레이션
- 🎯 **상황별 맞춤**: 10가지 생활 상황별로 분류된 위로의 말씀

## 🎨 주요 기능

### 1. 오늘의 말씀
- 날짜별로 매일 다른 성경 구절 제공
- 하루를 시작하는 영감과 위로

### 2. 상황별 카테고리 (10개)
- 💪 **스트레스와 압박**: 일과 가정의 균형, 과중한 업무
- 👨‍👩‍👧‍👦 **육아의 어려움**: 아이 양육과 교육
- 🕊️ **불안과 걱정**: 미래에 대한 불안
- 🌈 **우울과 무기력**: 의욕 저하와 우울감
- 💰 **재정적 어려움**: 경제적 부담
- ❤️ **관계의 갈등**: 부부, 가족, 직장 관계
- 🏥 **건강 문제**: 몸과 마음의 건강
- 🎯 **삶의 의미**: 인생의 방향과 목적
- 🙏 **감사와 희망**: 감사하는 마음
- 💡 **지혜와 결단**: 중요한 결정

### 3. 말씀 컬렉션
- 각 카테고리별 엄선된 성경 구절
- 총 30개의 실제 성경 말씀 수록
- 구절, 출처, 관련 태그 제공

## 🛠️ 기술 스택

- **프론트엔드**: React 18 + TypeScript
- **빌드 도구**: Vite
- **스타일링**: Tailwind CSS
- **폰트**: Noto Sans KR (Google Fonts)
- **배포**: (Vercel/Netlify 권장)

## 🚀 시작하기

### 필수 요구사항
- Node.js 18+
- npm 또는 yarn

### 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build

# 빌드 미리보기
npm run preview
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

## 📊 데이터 구조

### 성경 말씀 (Verse)
```typescript
{
  id: string;
  book: string;        // 성경책 이름
  chapter: number;     // 장
  verse: number;       // 절
  text: string;        // 말씀 본문
  reference: string;   // 출처 (예: "마태복음 11:28")
  categories: string[]; // 관련 카테고리
  tags: string[];      // 관련 태그
}
```

### 카테고리 (Category)
```typescript
{
  id: string;
  name: string;        // 카테고리 이름
  description: string; // 설명
  icon: string;        // 이모지 아이콘
  color: string;       // 테마 색상
  keywords: string[];  // 검색 키워드
}
```
