# 🛡️ Naver Pay Integration Fix - Ultimate Edition

**버전 2.0.0** | 안전하고 강력한 네이버페이 통합 솔루션

---

## ✨ 주요 기능

### 1. 옵션 전달 기능 ✅
- YITH WAPO 상품 옵션을 네이버페이 결제 화면에 자동 전달
- 선택한 옵션이 `[옵션: 톱상어]` 형식으로 표시

### 2. 화면 깨짐 방지 ✅
- 네이버페이에서 돌아올 때 모바일 뷰로 전환되는 문제 해결
- 항상 데스크톱 레이아웃 유지

### 3. 자가 진단 시스템 🔍
- 플러그인 의존성 자동 체크
- 충돌 가능한 플러그인 자동 감지
- 실시간 상태 모니터링

### 4. 안전 모드 🛡️
- 문제 발생 시 **자동으로 안전 모드 전환**
- 사이트는 계속 정상 작동
- 관리자 화면에서 문제 확인 및 해결 가능

### 5. 관리자 대시보드 📊
- 시각적 상태 모니터링
- 실시간 로그 확인
- 원클릭 진단 및 복구

## 🛡️ 안전 모드란?

### 작동 방식

1. **자동 감지**
   - 플러그인이 문제를 자동으로 감지
   - 필수 플러그인 누락
   - 플러그인 충돌
   - 치명적 오류 발생

2. **자동 전환**
   - 문제 감지 시 즉시 안전 모드로 전환
   - **사이트는 계속 정상 작동**
   - 플러그인 기능만 일시 중지

3. **복구**
   - 관리자 대시보드에서 문제 확인
   - 문제 해결 후 "안전 모드 해제" 버튼 클릭
   - 자동으로 진단 실행 후 정상 모드로 복귀

### 안전 모드에서 할 수 있는 것

- ✅ 사이트 정상 운영
- ✅ 상품 판매 계속
- ✅ 관리자 화면 접속
- ✅ 다른 플러그인 사용
- ❌ 네이버페이 옵션 전달 (일시 중지)
- ❌ 화면 깨짐 방지 (일시 중지)

## ❓ 문제 해결 (FAQ)

### Q1: 플러그인 활성화 후 대시보드가 안 보여요
**A:**
```
WordPress 관리자 > 플러그인 > 설치된 플러그인
→ "Naver Pay Integration Fix - Ultimate Edition" 찾기
→ 활성화 되어있는지 확인
→ 좌측 메뉴에서 "Naver Pay Fix" 찾기
```

### Q2: 상태 대시보드에서 모든 항목이 ❌ 에요
**A:**
```
필수 플러그인이 설치되지 않았습니다.
→ WooCommerce 설치 및 활성화
→ YITH WAPO 설치 및 활성화
→ Mshop Naverpay 설치 및 활성화
→ "진단 실행" 버튼 클릭
```

### Q3: 옵션이 여전히 네이버페이에 안 보여요
**A:**
```
1. F12 → Console 탭 확인
2. 에러 메시지 있는지 확인
3. 관리자 대시보드 > 최근 로그 확인
4. 안전 모드 활성화되어 있는지 확인
   → 활성화되어 있다면 "안전 모드 해제" 클릭
```

### Q4: 화면이 여전히 모바일처럼 보여요
**A:**
```
1. 브라우저 캐시 삭제 (Ctrl + Shift + Delete)
2. 관리자 대시보드 > "캐시 삭제" 버튼 클릭
3. 시크릿 모드로 테스트 (Ctrl + Shift + N)
4. F12 → Console 탭에서 "[Naver Pay Fix]" 메시지 확인
```

### Q5: 안전 모드가 자꾸 활성화돼요
**A:**
```
플러그인이 반복적으로 문제를 감지하고 있습니다.
→ 대시보드의 "발견된 문제" 섹션 확인
→ 해당 문제 해결 (필수 플러그인 설치 등)
→ "진단 실행" 후 "안전 모드 해제"
```

### Q6: 다른 플러그인과 충돌해요
**A:**
```
자동으로 안전 모드로 전환됩니다.
→ 대시보드에서 충돌하는 플러그인 확인
→ 충돌 플러그인 비활성화
→ "안전 모드 해제"
```

## 💡 고급 설정

### 개발자 모드

WordPress `wp-config.php`에 다음 추가:

```php
define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);
```

그러면 `/wp-content/debug.log`에 상세한 로그가 기록됩니다.

### 로그 레벨 변경

플러그인 파일에서 `log_message()` 함수의 레벨 필터링 가능:
- `info`: 일반 정보
- `warning`: 경고
- `error`: 에러
