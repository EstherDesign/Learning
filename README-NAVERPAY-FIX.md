# 네이버페이 옵션 전달 수정 가이드

## 문제점
- 상품 상세 페이지에서 YITH WAPO 플러그인으로 만든 옵션을 선택해도
- 네이버페이 결제 화면에서 선택한 옵션이 표시되지 않음

## 원인
네이버페이 플러그인(`mshop-npay`)이 주문 생성 시 YITH WAPO 추가 옵션 데이터를 수집하지 못함

## 해결 방법

### 1단계: 플러그인 파일 업로드

`fix-naverpay-options.php` 파일을 워드프레스 플러그인 폴더에 업로드:

```
wp-content/plugins/fix-naverpay-options/fix-naverpay-options.php
```

### 2단계: 플러그인 활성화

1. 워드프레스 관리자 페이지 접속
2. **플러그인 > 설치된 플러그인** 메뉴로 이동
3. **Naver Pay YITH WAPO Options Fix** 플러그인 찾기
4. **활성화** 버튼 클릭

### 3단계: 테스트

1. 상품 상세 페이지 접속 (예: https://dstone.co.kr/shop/halftoy_forest_dioramaset/)
2. 옵션 선택 (예: 늑대, 양, 나무늘보 등)
3. 네이버페이 결제 버튼 클릭
4. 네이버페이 결제 화면에서 **상품명에 옵션 정보가 포함되어 표시되는지 확인**

예시:
```
상품명: [하프토이] 숲 디오라마 세트 [옵션: 늑대]
```

## 코드 설명

### 주요 기능

1. **옵션 검증**: 옵션 미선택 시 경고 메시지 표시
2. **옵션 수집**: YITH WAPO 옵션 데이터 자동 수집
3. **옵션 전달**: 네이버페이 주문 데이터에 옵션 정보 포함
4. **옵션 표시**: 상품명에 선택한 옵션 표시

### 적용된 훅

- `mshop_npay_order_data`: 네이버페이 주문 데이터 필터
- `wp_footer`: 옵션 검증 JavaScript 추가
- `woocommerce_add_cart_item_data`: 장바구니 데이터에 옵션 저장
- `woocommerce_get_item_data`: 장바구니에 옵션 표시

## 대체 방법 (functions.php 사용)

플러그인 생성 대신 테마의 `functions.php`에 코드를 추가할 수도 있습니다:

1. **외관 > 테마 파일 편집기** 메뉴로 이동
2. 우측에서 `functions.php` 파일 선택
3. `fix-naverpay-options.php` 파일의 내용 복사 (첫 번째 `<?php` 제외)
4. `functions.php` 파일 맨 아래에 붙여넣기
5. **파일 업데이트** 버튼 클릭

## 문제 해결

### 옵션이 여전히 표시되지 않는 경우

1. **브라우저 콘솔 확인**:
   - F12 키 누르기
   - Console 탭에서 오류 메시지 확인

2. **플러그인 충돌 확인**:
   - 다른 플러그인 비활성화 후 테스트
   - 캐시 플러그인 비활성화 또는 캐시 삭제

3. **JavaScript 오류 확인**:
   - 콘솔에 "네이버페이 YITH WAPO 옵션 연동 스크립트 로드됨" 메시지 확인
   - "옵션 발견" 로그 확인
